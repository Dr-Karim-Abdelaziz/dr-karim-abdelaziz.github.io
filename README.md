# د. كريم عبد العزيز — تطبيق عيادة المسالك 🩺

تطبيق أندرويد لمرضى العيادة — **شغال بنفس نظام دوايا بالظبط**:
أي تعديل في الكود بيعمل ملف APK لوحده على GitHub.

## لينك تحميل التطبيق

بعد ما التعديل يدخل `main`:

**https://github.com/Dr-Karim-Abdelaziz/dr-karim-abdelaziz.github.io/releases/latest/download/dr-karim.apk**


> علشان المريضات ينزّلوه: **Settings ← General ← Danger Zone ← Change visibility ← Public**
> (الكود مفيهوش بيانات مرضى — كل بيانات المريض على موبايله بس).

## المشروع فيه إيه

| الفولدر | وظيفته |
|---|---|
| `web/` | **التطبيق نفسه** (HTML). بيانات العيادة في أول السكريبت في `index.html` ← `const CLINIC` |
| `web/faq.js` | أسئلة بوت «اسأل د. كريم» (مسالك) — كل إجابة `r: 0` = مسودة، `r: 1` = الدكتور راجعها |
| `lib/main.dart` | غلاف الأندرويد (بيعرض `web/` وبيفتح الواتساب والمشاركة والكاميرا) |
| `cloudflare/` | خدمة قراءة الروشتة + البوت — **نفس خدمة دوايا** (`dawaya-reader`) + إضافة `/api/faq-match` |
| `tool/` | سكريبتات البناء + مفتاح التوقيع (من GitHub Secrets) |
| `.github/workflows/build-apk.yml` | البناء الأوتوماتيك |

## إزاي التعديل بيتنشر

1. أي تعديل يتعمل في `web/` (مثلًا رقم العيادة).
2. GitHub Actions يبني APK جديد لوحده (حوالي 10 دقايق).
3. على `main`: النسخة الجديدة بتنزل على نفس اللينك، وبتتثبّت فوق القديمة والبيانات بتفضل.

## الآيفون + كود واحد للكل

- **صفحة التحميل** (اللي الكود QR بيفتحها): https://dr-karim-abdelaziz.github.io/
  أندرويد ← زرار تحميل الـ APK. آيفون ← «افتح التطبيق» + إزاي تضيفه للشاشة الرئيسية من Safari.
- **نسخة الويب** (نفس التطبيق): https://dr-karim-abdelaziz.github.io/app/
- بتتنشر لوحدها مع كل تعديل على `main` (`.github/workflows/pages.yml`).
  أول مرة بس: **Settings ← Pages ← Source: GitHub Actions**.
- في نسخة الويب: قراءة الروشتة والبحث الذكي في البوت مقفولين لحد ما خدمة Cloudflare تتحدّث (CORS).

## تعديل المحتوى من غير برمجة (Google Drive)

فولدر **«محتوى تطبيق د. كريم»**: https://drive.google.com/drive/folders/1ydHUKpTlL7GCOMbQZ5ga8LBBRL2kDG3I
أرقام الملفات في `web/index.html` ← `const SHEETS`. لازم الفولدر يكون **«أي حد معاه اللينك — قارئ»**.

| الملف | بيتحكم في |
|---|---|
| clinic | الاسم، التخصص، التليفونات، العنوان، المواعيد، سعر الكشف، طريقة الحجز، اللوكيشن |
| faq | أسئلة وإجابات «اسأل د. كريم» + علامة «راجعها الدكتور» |
| tips | النصايح حسب سبب المتابعة (حصوات، بروستاتا، …) |
| lists | علامات الخطر، تعليمات بعد العمليات، أدوية سريعة، أنواع المواعيد |

- كشف علامات الخطر في البوت والتوكن ورابط الخدمة **ثابتين في الكود** ومش في الملفات.

## خدمة Cloudflare

التطبيق بيكلّم خدمة دوايا الموجودة (`dawaya-reader`) — **قراءة الروشتة شغالة من غير أي تعديل**.
البحث الذكي في البوت (`/api/faq-match`) محتاج نشر النسخة اللي في `cloudflare/` مرة واحدة
(`cd cloudflare && npx wrangler deploy`). من غيرها البوت بيشتغل بالبحث المحلي عادي.

## ملاحظات

- مفتاح التوقيع بييجي من GitHub Secrets (`KEYSTORE_B64`) علشان كل نسخة تتثبّت فوق القديمة — مش محفوظ في الكود.
- التنبيهات: داخل التطبيق + زرار «أضف للتقويم» (تقويم جوجل بيرن حتى والتطبيق مقفول).
